🕒 Relógio Digital

Um relógio digital desenvolvido com HTML, CSS e JavaScript, exibindo horas, minutos e segundos em tempo real.
O projeto possui design moderno, cards individuais para cada unidade de tempo e uma interface totalmente responsiva, funcionando perfeitamente em computadores e dispositivos móveis.

Este projeto foi criado para praticar e demonstrar conhecimentos em:

Manipulação do DOM

Atualização dinâmica com setInterval()

Responsividade com Flexbox

Organização visual e hierarquia de UI

Estruturação básica de componentes front-end

O objetivo é apresentar um exemplo simples e elegante de como a lógica do JavaScript pode ser aplicada para criar interfaces úteis no dia a dia.
